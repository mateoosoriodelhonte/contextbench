# Code of conduct

We want technical disagreement without personal attacks. Contributors must treat other people
with respect, keep feedback about the work, and stop conduct that another person says is
unwelcome.

Harassment, threats, discriminatory language, sexual attention, deliberate exposure of private
information, and sustained disruption are not accepted in project spaces. Maintainers can edit or
remove comments, reject contributions, or block participation when needed to protect the project
and its contributors.

Report conduct problems through a private message to the repository owner. Include links or
screenshots that show the event. The owner will limit disclosure to people needed to review the
report and will state any conflict that prevents an impartial decision.
