# ContextBench

Debug and measure your RAG pipeline instead of guessing whether retrieval works.

ContextBench is a local-first workbench for document ingestion, chunking experiments, vector
and BM25 retrieval, hybrid reciprocal-rank fusion, optional reranking, and standard retrieval
evaluation. It is not a document chatbot. Core workflows use local data and need no LLM,
cloud service, account, telemetry, or paid API.

> V1 implementation is in progress on the `codex/v1-build` branch. See the public
> [ContextBench v1.0 milestone](https://github.com/mateoosoriodelhonte/contextbench/milestone/1).
